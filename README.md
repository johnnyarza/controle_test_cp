# Probeta Control

Records concrete compression tests (ensayos) and their specimens (probetas): rupture dates, strength,
reports, Excel export and QR labels.

| Folder | What it is |
|---|---|
| [`dotnet/`](dotnet/README.md) | The new program: C# / WPF on .NET Framework 4.8. All current work happens here. |
| [`legacy-java/`](legacy-java/README.md) | The original Java / JavaFX program, kept unchanged until the new one replaces it. |

Where the port stands: [dotnet/docs/porting-status.md](dotnet/docs/porting-status.md).
