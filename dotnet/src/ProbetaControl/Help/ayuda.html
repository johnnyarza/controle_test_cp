Primeros pasos

Probeta Control registra los ensayos de compresión de hormigón: cada ensayo es un pedido de un cliente (obra, dosificación, proveedor del hormigón) y tiene sus probetas, que se moldean, se rompen a una edad (7, 14, 28 días…) y dan la resistencia. El programa calcula la densidad, la resistencia y el porcentaje del fck, avisa qué probetas hay que romper e imprime los informes y las etiquetas.

La ventana tiene arriba las páginas: Ensayos (la página de inicio), Clientes, Proveedores, Materiales, Dosificaciones y Configuración. A la derecha están su usuario, Cerrar sesión y el botón ? que abre esta ayuda.

Pulse F1 en cualquier pantalla o ventana para abrir la ayuda en el tema de esa pantalla. Esta ventana de ayuda puede quedar abierta al lado mientras trabaja.

La primera vez

  1. Al abrir el programa en un equipo nuevo se pide la conexión a la base de datos.
  2. Si la base de datos es nueva o de una versión anterior, un administrador la actualiza.
  3. Una base de datos recién creada tiene un solo usuario del programa: admin con la contraseña admin. Al entrar por primera vez el programa obliga a elegir una contraseña nueva (mínimo 8 caracteres).
  4. Luego el administrador crea los usuarios de cada persona en Configuración → Usuarios.

Dos clases de "usuario"

No hay que confundirlas:

  • Usuarios del programa (admin y los operadores): se escriben en la pantalla Iniciar sesión. Cada persona tiene el suyo.
  • Cuentas de MySQL: las usa el programa para hablar con la base de datos. La conexión de cada equipo usa la cuenta del programa (por ejemplo specimen_app); para actualizar la base de datos se pide otra cuenta con más permisos (por ejemplo specimen_admin), que nunca se guarda.

Administradores y operadores

  • Operador: crea y modifica clientes, proveedores, materiales, dosificaciones, ensayos y probetas.
  • Administrador: además archiva y restaura registros, administra los usuarios, los datos del informe, el logo, el sello y las etiquetas, cambia dosificaciones que ya se usan y puede modificar cualquier ensayo.

Los botones que un operador no puede usar aparecen desactivados y su descripción (al pasar el ratón) dice por qué.

Conexión y base de datos

Cada equipo guarda su conexión en el archivo ProbetaControl.config, junto al programa, con la contraseña cifrada para ese equipo (no sirve copiarlo a otro equipo).

Conexión a la base de datos

  • Servidor y Puerto: el equipo donde está MySQL (nombre o IP) y su puerto (normalmente 3306).
  • Base de datos: el nombre de la base de datos del programa.
  • Usuario y contraseña de MySQL: la cuenta de MySQL del programa (por ejemplo specimen_app), no el usuario con el que usted inicia sesión.

Probar conexión comprueba los datos sin guardarlos; Guardar los guarda y continúa.

El programa rechaza una cuenta de MySQL que pueda borrar o cambiar la estructura de la base de datos (por ejemplo root): los registros nunca se borran, se archivan, y el programa no debe poder modificar las tablas. Use la cuenta del programa.

Actualizar la base de datos

Cuando la base de datos está vacía o es de una versión anterior del programa, aparece La base de datos necesita actualizarse. Con Actualizar base de datos se ingresa una cuenta de MySQL con permiso para cambiar la estructura (por ejemplo specimen_admin); su contraseña no se guarda. La actualización conserva todos los datos.

Si la base de datos es más nueva que el programa, hay que instalar la versión más reciente del programa en ese equipo.

Si no se puede conectar

  • No se pudo conectar al servidor: revise que el servidor esté encendido y que la red funcione; luego Reintentar.
  • El servidor rechazó el usuario o la contraseña: revise la cuenta de MySQL en Configurar conexión.
  • La base de datos indicada no existe: revise el nombre de la base de datos.
  • El servidor MySQL es muy antiguo: se necesita MySQL 8.0.20 o posterior.

Iniciar sesión

Escriba su Usuario y Contraseña del programa y pulse Entrar. El botón Conexión abre los datos de la conexión a la base de datos.

Un usuario archivado no puede entrar. Si olvidó su contraseña, un administrador puede restablecerla.

Cambiar la contraseña al entrar

Un usuario nuevo, o uno cuya contraseña restableció un administrador, debe elegir una contraseña nueva al entrar: la actual, la nueva (mínimo 8 caracteres, distinta de la actual) y la nueva otra vez.

Cerrar sesión (arriba a la derecha) vuelve a esta pantalla, por ejemplo antes de dejar el equipo.

Lista de ensayos

Es la página de inicio. Muestra los ensayos del más nuevo al más antiguo, de a 100; Mostrar más agrega los siguientes.

  • Para romper (número en rojo): probetas sin rotura cuya fecha de rotura es hoy o ya pasó.
  • Buscar: encuentra el número de ensayo, el cliente, el proyecto o la ubicación.
  • Cliente: Todos los clientes: abre la búsqueda de clientes para ver solo los ensayos de uno; la × quita el filtro.
  • Solo con probetas para romper (N): muestra solo esos ensayos; N los cuenta en todos los clientes.
  • Abrir, doble clic o Enter abre la página del ensayo.
  • Informe por cliente… imprime los ensayos de un cliente (ver Informes).

Nuevo ensayo y datos del ensayo

Nuevo (Ctrl+N) pide los datos y luego abre el ensayo nuevo para agregar sus probetas:

  • Fecha (hoy de forma predeterminada).
  • Cliente y Proveedor del hormigón, elegidos con Buscar…; Igual que el cliente copia el cliente como proveedor.
  • Dosificación, Proyecto / obra y Ubicación.

Los mismos datos se cambian después con Editar datos en la página del ensayo.

Buscar cliente

Escriba parte del nombre, teléfono o correo. Doble clic, Enter o Elegir elige el cliente; si hay una sola coincidencia ya está seleccionada. Solo aparecen los clientes activos. Al elegir el cliente o el proveedor de un ensayo, Nuevo cliente crea uno (con el nombre buscado) y lo elige de inmediato.

Página del ensayo

Arriba: el número y el proyecto, el estado del bloqueo y los botones Imprimir, Excel, Etiquetas y Editar datos. Debajo, los datos del ensayo en una línea y cuatro recuadros: probetas, para romper, rotas y resistencia media (con el % del fck). Los recuadros cuentan siempre todo el ensayo, con filtro o sin él. ← Ensayos (Alt+←) vuelve a la lista como estaba.

Colores y estado

  • Rojo: retrasada (la fecha de rotura pasó y no se rompió).
  • Amarillo: romper hoy o mañana.
  • Gris: archivada (solo con Mostrar archivadas).

La columna Estado dice lo mismo con palabras (Retrasada, Hoy, Mañana, Pendiente, Rota). % fck es la resistencia de cada probeta rota como porcentaje del fck de la dosificación; a edades tempranas es normal que sea menor.

Ensayos bloqueados

Un operador puede cambiar los ensayos que creó desde que inició sesión. Los demás están bloqueados: se pueden ver, y solo se puede registrar la rotura de una probeta que vence hoy o después. Las probetas retrasadas o ya rotas, y los cambios de medidas, necesitan un administrador.

Desbloquear… pide el usuario y la contraseña de un administrador y desbloquea ese ensayo para el operador hasta que pulse Bloquear o cierre la sesión. Los administradores siempre pueden cambiar todo.

Filtrar probetas

Filtrar… muestra solo las probetas moldeadas entre dos fechas y/o con ciertos números, por ejemplo 1-5, 8, 10-12. El filtro activo aparece en una barra azul con Quitar filtro. Imprimir, Excel y Etiquetas usan las probetas del filtro.

Con clic derecho sobre una probeta: Registrar rotura, Editar, Copiar, Imprimir etiqueta… y Archivar.

Probetas

Nueva probeta (Ctrl+N) abre el formulario, en secciones:

  • Identificación: descripción (por ejemplo "Losa eje A") y slump.
  • Fechas: Moldeo + Edad = Rotura. Hoy pone la fecha de moldeo; la edad en días o los botones 7, 14, 28 calculan la fecha de rotura. Cambiar la fecha de rotura cambia la edad; cambiar la fecha de moldeo conserva la edad.
  • Medidas: diámetro, altura y peso. La densidad se ve mientras escribe.
  • Rotura: la carga en toneladas; se ven la resistencia y el % del fck.

Una probeta nueva empieza con el slump, el diámetro y la altura de la probeta más nueva del ensayo (una nota lo indica); el peso y las fechas se escriben cada vez. Al guardar, las medidas quedan bloqueadas (como en el programa anterior).

Promedio de dos lecturas

El botón de calculadora junto a Diámetro y Altura promedia dos lecturas y pone el resultado en el campo.

Copiar

Copiar crea una probeta nueva con las medidas y fechas de la seleccionada, sin su carga de rotura.

Registrar rotura

Registrar rotura (botón, Ctrl+R, clic derecho, o doble clic / Enter sobre una probeta sin rotura) abre una ventana pequeña: los datos de la probeta, un campo grande para la carga (t) y la resistencia y el % del fck que resultan.

Guardar y siguiente (Nº X) guarda y abre la siguiente probeta que vence hoy o antes, para romper las probetas del día una tras otra. Doble clic en una probeta ya rota abre el formulario completo.

Aviso de probetas para romper

Aparece al iniciar sesión si hay probetas sin romper con fecha de rotura hoy, mañana o retrasadas hasta 30 días. Las agrupa por ensayo: primero las de hoy, luego las de mañana y después las retrasadas, con los mismos colores que la página del ensayo.

  • Abrir ensayo cierra el aviso y abre ese ensayo.
  • Las retrasadas hace más de 30 días no se listan una por una: una línea dice cuántas son y Ver en Ensayos muestra la lista con "Solo con probetas para romper".
  • No volver a mostrar hoy en este equipo lo oculta hasta mañana, solo en este equipo y usuario de Windows. La lista de ensayos sigue mostrando "Para romper".

Informes e impresión

Todos los informes se abren en una vista previa del propio programa; no hace falta un programa de PDF. Los datos se leen de nuevo de la base de datos, así que el informe siempre está al día.

Informe del ensayo

Imprimir (Ctrl+P) en la página del ensayo. Imprime las probetas que muestra la página (con el filtro, si hay), nunca las archivadas. Contiene: logo, título, nombre del laboratorio, número y fecha del ensayo, fecha de impresión y "Hoja X de Y"; cliente, proveedor, proyecto, ubicación, dosificación con fck, slump con su tolerancia y a/c; la mezcla por m³; la tabla de probetas ("—" = todavía sin romper); un resumen por edad (cantidad, mínimo, promedio, % fck) con el gráfico de resistencia según la edad; la nota y el sello; la dirección del laboratorio al pie de cada hoja.

Vista previa

  • Imprimir… (Ctrl+P): elige impresora, copias y hojas "Desde/Hasta".
  • Guardar PDF… (Ctrl+S): guarda un PDF, por ejemplo para enviarlo por correo.
  • Ctrl+− / Ctrl++ cambian el tamaño; Ancho de página (Ctrl+0) lo ajusta a la ventana.
  • Cerrar o Esc.

El papel (A4 o Carta) se elige en Datos del informe. Si la impresora no tiene ese papel, la hoja se reduce para que entre completa en vez de cortarse.

Listados

Imprimir (Ctrl+P) en Clientes, Proveedores, Materiales y Dosificaciones imprime el listado con todo lo que encuentra la búsqueda (no solo las 100 filas de la pantalla). Los archivados se incluyen solo con "Mostrar archivados" y se marcan "(archivado)". Las dosificaciones se imprimen una por bloque, con sus materiales y el total, sin cortarse entre hojas.

Informe por cliente

Informe por cliente… en Ensayos. Con el filtro de cliente usa ese cliente; si no, lo pide. Luego pide Ensayos desde / Ensayos hasta (fecha del ensayo, ambas incluidas; vacías = todos). El informe lista las probetas de esos ensayos, del más antiguo al más nuevo, con una línea por ensayo. No incluye ensayos ni probetas archivados, ni ensayos donde el cliente es solo el proveedor del hormigón.

Un listado o informe por cliente se detiene en 3.000 filas (unas 100 hojas) y lo dice al final: acote la búsqueda o las fechas.

Exportar a Excel

Excel (Ctrl+E) en la página del ensayo guarda un archivo .xlsx con las probetas que muestra la página (con el filtro, si hay), nunca las archivadas. No hace falta tener Excel para exportar, solo para abrir el archivo.

  • Hoja Probetas: una fila por probeta, con números y fechas con los que Excel puede calcular, el encabezado fijo arriba y flechas de filtro. Una probeta sin romper deja vacíos la carga, la resistencia y el % fck.
  • Hoja Ensayo: cliente, proyecto, dosificación, fck y la mezcla.

Si el archivo está abierto en Excel no se puede reemplazar: ciérrelo y vuelva a exportar.

Etiquetas QR

Etiquetas (Ctrl+L) en la página del ensayo imprime una etiqueta adhesiva por probeta de la página (con el filtro, si hay; nunca las archivadas). Solo probetas sin romper (marcado de forma predeterminada) deja fuera las rotas. Con clic derecho sobre una probeta, Imprimir etiqueta… imprime solo esa, rota o no, por ejemplo para reponer una etiqueta dañada.

Empezar en una hoja ya usada

La ventana dibuja la primera hoja: gris = ya usada, azul = se imprime, blanco = queda libre. Haga clic en la primera etiqueta libre para empezar allí. El resumen dice cuántas etiquetas y hojas se usan. Ver etiquetas abre la vista previa para imprimir.

Qué lleva cada etiqueta

El código QR a la izquierda; a la derecha el número de probeta en letra grande, "Ensayo N", la fecha de rotura con la edad en días y el cliente (acortado a una línea).

El QR lleva una dirección en el servidor del laboratorio: http://nombre-del-servidor/p/código. El código es al azar (no es el número de la probeta), así nadie puede ver otros resultados cambiando un número. La página que se abre con el QR llegará en una versión posterior; el código de cada probeta ya queda guardado y nunca cambia.

No se pueden imprimir etiquetas hasta que un administrador indique el nombre del servidor en Configuración → Etiquetas.

En hojas sin márgenes, la mayoría de las impresoras no imprime los últimos 3 o 4 mm del papel. El contenido de la etiqueta se aleja de los bordes, pero si la impresora corta el QR de las etiquetas de afuera, use hojas con márgenes.

Clientes y proveedores

Las listas de Clientes y Proveedores se buscan por nombre, teléfono o correo. Nuevo (Ctrl+N) y Editar (o doble clic, o Enter) abren el formulario; el nombre es obligatorio y no se puede repetir.

Menú de clic derecho

Clic derecho sobre una fila (o la tecla de menú, o Shift+F10) la selecciona y ofrece Editar y Archivar (Restaurar si está archivada), igual que los botones de arriba. Dosificaciones también tiene Duplicar.

Un cliente es también "proveedor del hormigón" en los ensayos; los proveedores son los de los materiales (cemento, áridos, aditivos…).

Materiales

Cada material tiene nombre, proveedor y Tipo: Cemento, Agua, Agregado, Aditivo u Otro. El tipo sirve para calcular la relación agua/cemento de las dosificaciones (a/c = kg de Agua / kg de Cemento).

Al actualizar la base de datos desde una versión anterior, los materiales reciben un tipo adivinado por su nombre (cemento…, agua…, arena/grava/piedra/árido…, aditivo…); los demás quedan como "Otro" y conviene revisarlos una vez.

Dosificaciones

La lista muestra descripción, fck, slump, a/c y la cantidad de materiales. El panel de abajo muestra los materiales de la dosificación seleccionada (#, material, proveedor, tipo, kg/m³) con el total; arrastre la barra entre ambos para dar más lugar a uno.

Tabla de materiales

  • Una fila por material con sus kg/m³, hasta 8 filas; se necesita al menos un material.
  • Agregar material agrega una fila; el tacho la quita; las flechas cambian el orden, que es el orden en que se guarda e imprime.
  • Cada fila solo ofrece materiales que no están en otra fila. Las filas vacías se ignoran al guardar.
  • Debajo se ven el total de kg/m³ y la relación a/c ("—" hasta que haya Cemento y Agua con cantidades).

Calculadora de porcentaje

Calcula la cantidad de un material como porcentaje de otro (destino = origen × % / 100), por ejemplo un aditivo al 0,8 % del cemento. Necesita al menos dos materiales y la cantidad del origen; muestra el resultado antes de Aplicar. No guarda: la dosificación se guarda con Guardar.

Dosificaciones usadas por ensayos

Al abrir una dosificación que usan ensayos (también archivados) aparece un aviso con la cantidad: cambiarla cambia también los datos e informes de esos ensayos. Solo un administrador puede cambiarla; un operador la ve sin poder modificarla. Para cambiar una mezcla en uso sin tocar los informes anteriores, cree una nueva con Duplicar.

Duplicar

Abre una dosificación nueva con el mismo fck, slump, materiales y cantidades, llamada "… (copia)". La descripción no se puede repetir: cámbiela antes de guardar. Los materiales archivados no se copian (una nota amarilla los nombra).

Archivar y restaurar

En Probeta Control nada se borra: los registros se archivan. Un registro archivado deja de aparecer en las listas y en las búsquedas; Mostrar archivados lo muestra en gris y Restaurar lo devuelve. Archivar y restaurar es solo para administradores.

Registros en uso

No se puede archivar un registro que usan otros registros activos. El aviso nombra hasta 5 de ellos y cuántos más hay:

  • un cliente: ensayos activos donde es el cliente o el proveedor del hormigón;
  • un proveedor: materiales activos;
  • un material: dosificaciones activas;
  • una dosificación: ensayos activos.

Los archivados no cuentan: archive primero esos registros (o cambie el material o proveedor en ellos). Restaurar nunca se bloquea. Una dosificación sigue mostrando un material que se archivó después, marcado "(archivado)".

Números y fechas

Decimales

Todos los campos numéricos aceptan coma o punto como separador decimal ("12,5" = "12.5"). No se aceptan separadores de miles ("1.234,5" da "Número no válido."), así un valor nunca se lee mal. Las listas muestran punto.

Fechas

Se escriben con el día primero: "05/11/2026", "5/11/26", "5-11-2026" y "5.11.2026" son el 5 de noviembre de 2026 (la configuración regional del equipo no importa). El botón de calendario (o Alt+↓ / F4) abre un calendario; al salir del campo la fecha queda como dd/mm/aaaa.

Configuración

Un menú a la izquierda con las secciones. Los administradores ven Usuarios, Datos del informe, Logo y sello, Etiquetas, Conexión, Mi contraseña y Acerca de; los operadores, Conexión, Mi contraseña y Acerca de.

Usuarios

Nuevo usuario pide el nombre de usuario (sin espacios), el nombre completo, el rol y una primera contraseña (mínimo 8 caracteres) que el usuario debe cambiar al entrar. Restablecer contraseña… pone una contraseña temporal con la misma regla. Archivar impide que el usuario entre (nunca se borra). Su propio usuario no se puede archivar ni restablecer aquí (use Mi contraseña), no puede cambiar su propio rol, y siempre debe quedar un administrador activo.

Datos del informe

Nombre del laboratorio (obligatorio), pie de página (dirección, teléfonos, correo), nota (junto al sello en el informe del ensayo) y tamaño de papel (A4 o Carta). Se guardan en la base de datos: todos los equipos imprimen igual.

Logo y sello

Las imágenes de los informes, guardadas en la base de datos. PNG o JPG, hasta 2 MB; un archivo que solo tiene nombre .png o .jpg pero es de otro formato se rechaza. La imagen se guarda al elegirla; Quitar la quita.

Etiquetas

  • Nombre del servidor: el nombre del equipo servidor en la red del laboratorio, no su IP (la IP puede cambiar y las etiquetas ya pegadas no se podrían corregir); "localhost" tampoco sirve. Cambiarlo después no cambia las etiquetas ya impresas.
  • Hoja de etiquetas (A4): elija una hoja común de la lista, o escriba las medidas impresas en el paquete ("Personalizada"): columnas, filas, ancho y alto de la etiqueta, márgenes superior e izquierdo y separaciones, en mm.
  • Hoja de prueba imprime el contorno y el número de cada etiqueta con las medidas escritas (sin guardarlas). Imprímala en papel común y póngala sobre una hoja de etiquetas a contraluz: los recuadros deben coincidir; si se corren, ajuste los márgenes.

Las etiquetas son siempre A4, aunque los informes usen Carta, y se imprimen a tamaño real.

Conexión

Muestra el servidor, la base de datos y la cuenta de MySQL de este equipo. Cambiar conexión… cierra la sesión y abre el formulario de conexión; después de guardar, inicie sesión otra vez.

Mi contraseña

La contraseña actual y la nueva dos veces (mínimo 8 caracteres, distinta de la actual).

Acerca de

Versión del programa y de la base de datos, versión del servidor MySQL, nombre del equipo y la carpeta de registros (Abrir carpeta de registros). Útil al pedir soporte.

Problemas frecuentes

No hay impresora

Imprimir… lo dice. Guarde el PDF con Guardar PDF… e imprímalo en otro equipo.

No se pudo guardar el archivo de Excel

Probablemente está abierto en Excel. Ciérrelo y vuelva a exportar, o guárdelo con otro nombre.

"Otro usuario modificó este registro"

Alguien guardó el mismo registro mientras usted lo tenía abierto. Cierre la ventana, vuelva a abrirlo (verá los datos nuevos) y repita su cambio.

No puedo cambiar una probeta

El ensayo está bloqueado para usted (ver Ensayos bloqueados): pida a un administrador que lo desbloquee.

No puedo imprimir etiquetas

Falta el nombre del servidor: un administrador debe indicarlo en Configuración → Etiquetas.

El programa no se conecta

Ver Si no se puede conectar. Si el problema sigue, abra Configuración → Acerca de (o la carpeta de registros) y envíe al soporte la versión del programa y el registro del día.

No se encontró nada. Pruebe con otra palabra.
